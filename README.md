## 📌 Descrição da 1ª Fase
Esta primeira fase implementa as bases de gestão de informação e estruturas de dados do sistema. Foram desenvolvidas as bibliotecas para carregar as configurações das entidades cotadas em bolsa através de ficheiros de texto, um sistema reentrante de registo de eventos (logs) e a funcionalidade de guardar o estado do mercado de forma segura na terminação do servidor. O sistema foi desenvolvido e testado em ambiente Linux (WSL/Ubuntu).
